# 프로젝트 뷰에서 파일과 폴더를 Claude에게 보내기

> 언어: [English](./en.md) · **한국어**

**Send to Claude Code**(Alt+K)는 지금까지 편집 중인 파일을 `@` 멘션으로 입력창에 넣어 왔습니다. 이제 같은 항목이 메뉴 두 곳에 더 생겨, 파일을 열지 않고도 Claude에게 건넬 수 있습니다.

- **프로젝트 뷰**: 파일이나 폴더 하나 이상을 우클릭합니다.
- **에디터 탭**: 탭 제목을 우클릭합니다.

프로젝트 뷰에서 여러 파일과 폴더를 한꺼번에 고르면(Ctrl/Cmd 클릭, Shift 클릭) 전부 함께 들어갑니다. 같은 항목이 있는 CC GUI 플러그인에서 가져왔습니다.

![영어 인터페이스의 채팅 입력창. "Compare @src/a.ts @src/lib/ @"My Notes.md" and @README.md#L3-9"가 들어 있고, 멘션마다 파란 칩으로 그려져 있습니다. 고른 파일 둘, 폴더 하나, 그리고 Alt+K로 넣은 README의 줄 범위입니다.](./assets/composer-mentions.png)

이번 버전은 Alt+K가 쓰는 줄 범위도 고칩니다. 이전에는 3~9번 줄을 고르면 `@README.md#L3-L9`로 적혔는데, CLI는 이것을 범위로 읽지 않아 Claude가 **파일 전체**를 받았습니다. 이제 `@README.md#L3-9`로 적혀 Claude가 딱 그 줄만 받습니다([아래](#줄-범위-수정) 참고).

## 입력창에 들어가는 모양

| 고른 것 | 적히는 모양 |
|---------|-------------|
| 파일 | `@src/a.ts` |
| 폴더 | `@src/lib/`. CLI 자신의 `@` 자동완성처럼 끝에 슬래시가 붙습니다 |
| 프로젝트 폴더 자체 | `@./` |
| 경로에 공백이 있는 파일 | `@"My Notes.md"`. CLI가 읽는 따옴표 형식입니다 |
| 프로젝트 밖의 파일 | 절대 경로 |
| 위의 것 여러 개 | 고른 순서대로 전부, 공백으로 구분 |

경로는 프로젝트 기준 상대 경로입니다. 멘션은 커서 위치, 이미 입력한 글 뒤에 들어가고 입력창이 포커스를 받습니다. Alt+K와 같은 방식입니다. **아무것도 전송되지 않습니다**. 질문을 덧붙이고 Enter는 직접 누르세요.

들어가는 것은 평범한 `@` 멘션입니다. 보내면 Claude Code CLI가 터미널에서 직접 친 것과 똑같이 읽습니다. 파일은 내용이 첨부되고, 폴더는 목록이 전달됩니다.

![보낸 메시지에 "@src/a.ts", "@"My Notes.md"", "@README.md#L3-5" 칩이 있고, 이어지는 Claude의 답이 보입니다: "src/a.ts: the whole file (1 line)", "My Notes.md: the whole file (2 lines)", "README.md: only lines 3–5".](./assets/sent-message.png)

## 어느 채팅으로 가나

Alt+K와 같은 곳, 즉 마지막으로 사용한 Claude Code 패널입니다. 그것이 standalone 모드의 브라우저 탭이면 멘션은 거기로 가고 IDE는 그대로 둡니다. 열린 채팅이 없으면 새 Claude Code 탭이 열리고 그 입력창에 멘션이 들어갑니다.

## 줄 범위 수정

Claude Code CLI는 멘션의 줄 범위를 `#L<시작>-<끝>` 형식으로 알아봅니다. Alt+K는 지금까지 `L`이 하나 더 붙은 `#L<시작>-L<끝>`을 썼습니다. CLI는 이 형식을 알아보지 못하고 파일 전체를 첨부했기 때문에, Claude는 어느 줄을 말하는지 알 수 없었습니다.

30줄짜리 파일로 CLI에 직접 확인한 결과입니다.

| 멘션 | Claude가 받은 것 |
|------|------------------|
| `@data.txt#L10-L12` (이전) | 1~30번 줄 |
| `@data.txt#L10-12` (지금) | 10~12번 줄 |

한 줄만 고르면 이제 `#L10`으로 적힙니다. 채팅 기록에 이미 남아 있는 이전 형식의 멘션은 지금도 그대로 표시되고 IDE에서 열립니다. 영향을 받은 것은 Claude가 받은 내용뿐이었습니다.

## 한계

- **디스크에 있는 파일만.** 라이브러리 jar 안의 파일은 CLI가 읽을 수 있는 경로가 없어서, 그런 파일에는 항목이 나타나지 않습니다.
- **한 번에 최대 200개.** 그보다 많이 고르면 200개에서 잘립니다.
- **폴더는 펼치지 않고 멘션만 합니다.** Claude는 터미널의 `@folder/`처럼 폴더 목록을 받지, 안의 파일 전부를 받지는 않습니다.
- **IDE 전용.** 프로젝트 뷰와 에디터 탭은 IDE에만 있습니다. standalone 모드에서는 입력창에 `@`를 쳐서 파일을 고르세요.

## 자주 묻는 질문

**파일을 골랐는데 메뉴 항목이 흐리거나 없어요.** 고른 것이 CLI가 읽을 수 없는 파일(jar 안)이나 Claude Code 탭 자체뿐일 수 있습니다.

**폴더 안 내용을 통째로 보낼 수 있나요?** 폴더를 멘션하고 필요한 것을 읽어 달라고 하세요. Claude가 파일을 직접 열 수 있습니다. 모든 파일을 한꺼번에 첨부하면 컨텍스트가 금방 찹니다.

**이걸 누르면 메시지가 전송되나요?** 아니요. 입력창만 채우므로 보내기 전에 지시를 덧붙일 수 있습니다.
