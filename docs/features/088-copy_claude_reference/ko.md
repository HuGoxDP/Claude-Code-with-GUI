# 파일과 선택한 줄을 Claude Code 참조로 복사하기

> 언어: [English](./en.md) · **한국어**

에디터에서 우클릭하고 **Copy Claude Code Reference**를 고르면, 파일과 선택한 줄이 Claude Code가 읽는 파일 참조 형식으로 클립보드에 들어갑니다.

```
@src/auth/login.ts#L42-57
```

채팅 입력창이 없는 곳에 붙여 넣을 때 씁니다. 터미널의 Claude Code 세션, 자기 메모, Claude Code를 쓰는 동료에게 보내는 메시지 같은 곳입니다. Claude는 정확히 그 줄들을 읽습니다. 채팅 안에서는 **Send to Claude Code**(Alt+K)가 같은 글을 바로 넣어 주므로, 이 항목은 다른 곳에 붙일 때만 필요합니다. 같은 항목("Copy AI Reference")이 있는 CC GUI 플러그인에서 가져왔습니다.

IDE 창 아래의 상태 표시줄이 무엇을 복사했는지 알려 줍니다("Copied @src/auth/login.ts#L42-57").

## 복사되는 것

| 에디터 상태 | 복사되는 글 |
|-------------|-------------|
| 선택 없음 | `@src/a.ts`, 파일 전체 |
| 10~12번 줄 선택 | `@src/a.ts#L10-12` |
| 한 줄의 일부 선택 | `@src/a.ts#L10` |
| 줄 전체 선택(세 번 클릭, Shift+Down) | 선택한 줄만. 다음 줄의 빈 시작은 세지 않습니다 |
| 경로에 공백이 있는 파일 | `@"My Notes.md#L3-5"`. CLI가 읽는 따옴표 형식입니다 |
| 프로젝트 밖의 파일 | 절대 경로 |

경로는 Alt+K가 쓰는 것과 같이 프로젝트 폴더 기준 상대 경로라서, 프로젝트에서 시작한 Claude Code 세션에서 통합니다. 다른 곳에서 시작한 세션에는 절대 경로가 필요하며, IDE 자체의 **Copy Path/Reference** 메뉴로 얻을 수 있습니다.

줄 범위는 Claude Code CLI가 범위로 읽는 유일한 형식인 `#L10-12`로 적힙니다. `L`이 하나 더 붙은 `#L10-L12`는 CLI가 파일 전체를 첨부하게 만듭니다([파일과 폴더 보내기](../087-send_files_from_project_view/ko.md#줄-범위-수정) 참고).

## 함께 고친 것: 줄 전체를 선택하면 Alt+K가 한 줄을 더 셌습니다

세 번 클릭이나 Shift+Down으로 줄 전체를 선택하면 선택은 다음 줄의 맨 앞에서 끝납니다. **Send to Claude Code**는 그 줄까지 세어서, 3~5번 줄을 선택하면 `#L3-6`으로 적었습니다. 이제 `#L3-5`로 적으며, 새 항목도 마찬가지입니다.

## 한계

- **IDE 전용.** 에디터 우클릭 메뉴는 IDE에만 있습니다. standalone 모드에서는 입력창에 `@`를 쳐서 파일을 고르세요.
- **Claude Code 패널 안에서는 보이지 않습니다.** 패널은 Claude가 읽을 수 있는 파일이 아니기 때문입니다.
- **아무것도 전송되지 않습니다.** 클립보드만 채웁니다.

## 자주 묻는 질문

**터미널 세션에 참조를 붙였더니 Claude가 파일 전체를 읽었어요.** 범위에 두 번째 `L`이 없는지 확인하세요. 이 항목이 복사한 참조에는 없지만, 손으로 친 참조에는 있을 수 있습니다.

**여러 파일을 한 번에 복사할 수 있나요?** 이 항목으로는 안 됩니다. 여러 파일을 채팅 입력창에 넣으려면 프로젝트 뷰에서 골라 그곳의 **Send to Claude Code**를 쓰세요.
