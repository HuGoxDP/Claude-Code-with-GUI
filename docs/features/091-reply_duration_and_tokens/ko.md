# 답변에 걸린 시간과 사용한 토큰

> Language: [English](./en.md) · **한국어**

Claude가 답을 마치면 답변 아래 작은 줄에 그 턴이 걸린 시간과 사용한 토큰이 나옵니다. 마지막 답변 아래 같은 정보를 보여 주는 CC GUI 플러그인에서 가져왔습니다.

![영어 화면의 답변. "HTTP status code 429 means "Too Many Requests.""와 그 아래 복사 버튼·시각 밑에, 시계 아이콘과 함께 회색으로 "Took 0:01 · 17.6K in · 21 out"이라고 적힌 줄이 있다.](./assets/turn-line.png)

## 줄이 말하는 것

| 부분 | 뜻 |
|---|---|
| **Took 0:01** | 턴이 시작된 순간부터 Claude가 마친 순간까지, 분:초로(한 시간이 넘으면 `1:02:05`). 답변을 쓰는 시간만이 아니라 도구 호출을 포함한 턴 전체입니다. |
| **17.6K in** | 그 턴이 모델에 보낸 모든 입력 토큰. 여러 번 요청했다면 전부 합한 값이며, 새 입력·프롬프트 캐시에 쓴 입력·캐시에서 읽은 입력이 모두 들어갑니다. |
| **21 out** | 모델이 쓴 토큰. |

토큰 수에 마우스를 올리면 입력이 나뉘어 나옵니다. 예: *"Input: 2 new, 3.9K written to cache, 13.7K read from cache. Output: 21."* 긴 대화의 입력은 대부분 캐시에서 읽히고, 캐시 읽기는 새 입력보다 싸고 빠르므로, 합계보다 이 내역이 더 많은 것을 알려 줍니다.

숫자는 Claude Code가 직접 보낸 것입니다. 매 턴 끝에 보내는 요약(`result` 이벤트)을 고치지 않고 그대로 씁니다.

## 언제 나오나

- **모델에 닿은 모든 답변 아래**, 지금 보고 있는 대화에서 턴이 끝나자마자 나옵니다.
- **토큰을 쓰지 않은 턴에는 없습니다.** Claude Code가 스스로 답하는 슬래시 명령(`/cost`)이나 보내기 전에 거절된 요청이 그렇습니다. 시간만 적힌 줄은 잡음일 뿐이라서입니다.
- 내 메시지 옆 화살표로 **답변을 접으면** 그 줄도 함께 숨습니다.

## 한계

- **보고 있는 동안만 있습니다.** Claude Code는 이 요약을 실시간으로만 보내고 세션 파일에 쓰지 않습니다. 대화를 다시 열거나 페이지를 새로고침하거나 IDE를 다시 시작하면 이전 답변들의 줄은 사라집니다. 대화 자체에는 영향이 없습니다.
- **비용은 보여 주지 않습니다.** Claude Code는 비용을 답변마다가 아니라 프로세스 단위의 누계로 알려 줍니다. 한 단어 답변 두 개를 연달아 받았을 때 $0.048, 이어서 $0.078이었습니다. 이 누계는 프로세스가 다시 시작될 때마다(예: 세션 이어 하기) 처음부터 세므로, 여기에 어떤 숫자를 보여 줘도 "이 답변의 비용"이라고 정직하게 부를 수 없습니다. CC GUI는 상세 모드에서 비용을 보여 주지만, 이 플러그인은 틀릴 수 있는 숫자를 보여 주는 대신 빼 두었습니다.
- **턴 전체만 보여 줍니다.** 도구를 여러 번 쓰는 턴은 모델에 여러 번 요청하는데, 줄은 그것을 합쳐서 보여 주고 하나씩 나열하지 않습니다.

## 자주 묻는 질문

**"in"이 내가 쓴 것보다 훨씬 큰 이유는?** 요청마다 지금까지의 대화 전체와 Claude Code의 지침·도구 설명이 함께 가기 때문입니다. 그 대부분은 캐시에서 읽히며, 마우스를 올리면 내역이 보입니다.

**이게 요금제 한도에 영향을 주나요?** 이 줄은 사용량을 보여 줄 뿐 바꾸지 않습니다. 요금제 한도는 사용량 패널에서 볼 수 있습니다.
