# IDE 상태 표시줄에 보이는 채팅 상태

> Language: [English](./en.md) · **한국어**

에디터에서 일하는 동안 채팅은 흔히 그 뒤에 가려져 있습니다. 이제 IDE 상태 표시줄이 대신 지켜봐 줍니다. Claude가 아직 쓰고 있는지, 내 답을 기다리고 있는지, 대화가 컨텍스트 창을 얼마나 썼는지를 보여 주고, 누르면 채팅을 다시 앞으로 가져옵니다. CC GUI 플러그인의 상태 표시줄 위젯에서 가져왔습니다.

## 무엇을 보여 주나

IDE 창 맨 아래의 상태 표시줄, Claude Code 백엔드 점 옆에 짧은 줄이 생깁니다.

```
Claude: working · 34% context
Claude: waiting for you · 34% context
Claude: 34% context
Claude
```

위는 영어 화면의 문구입니다. 한국어 인터페이스에서는 `Claude: 작업 중 · 컨텍스트 34%`처럼 나옵니다.

- **작업 중**: Claude가 답을 쓰는 중입니다.
- **답변 대기**: Claude가 무언가(권한, 승인할 계획, 질문)를 묻고 답을 기다립니다.
- **컨텍스트 34%**: 대화가 컨텍스트 창을 얼마나 썼는지입니다. 채팅 입력창의 게이지(`34% used`)와 같은 숫자입니다. Claude Code가 창의 크기를 알려 주는 첫 답 이후에 나타나고, 그 전에는 아는 것만 보입니다.
- **Claude**만 있을 때: 채팅이 쉬고 있고 컨텍스트를 아직 모르는 경우입니다. 새 채팅이 그렇습니다.

마우스를 올리면 나머지가 보입니다.

```
Fix the login form
Model: Sonnet
Mode: Plan mode
Context: 34% used (68,000 tokens)
Click to show this chat
```

첫 줄은 대화의 제목입니다(시작하지 않은 대화는 "새 채팅"). 그래서 상태 표시줄이 어느 채팅 이야기를 하는지 알 수 있습니다. 모델은 채팅 입력창이 부르는 이름 그대로이고, 채팅이 모델 목록을 불러오기 전에는 이 줄을 빼 둡니다.

문구는 인터페이스 언어(**설정 → 일반 → 인터페이스 언어**)를 따릅니다. 모드 이름은 채팅 입력창이 부르는 그대로입니다.

## 어느 채팅을 보여 주나

상태 표시줄에는 채팅 하나만 들어가므로 **마지막으로 들어가 있던 채팅**을 보여 줍니다. 채팅을 클릭하거나 그 안에서 입력하면 상태 표시줄이 그 채팅을 따라갑니다. 에디터에서 일하는 동안에도 그 채팅을 계속 보여 줍니다. 상태 표시줄이 쓸모 있는 때가 바로 그때니까요.

- 다른 탭에서 일하고 있는 채팅이 내가 있던 채팅의 자리를 빼앗지 않습니다. 그 채팅의 탭 아이콘은 여전히 일하는 동안 돕니다.
- 채팅에서 설정 화면으로 나가거나 그 탭을 닫으면, 상태 표시줄은 그 전에 있던 채팅으로 돌아갑니다. 열린 채팅이 없으면 줄이 비어 있습니다.
- 프로젝트 창마다 상태 표시줄이 따로 있고, 그 창의 채팅을 보여 줍니다.

**줄을 누르면** 그 채팅이 에디터 탭이든 도구 창이든 있는 곳에서 앞으로 나옵니다.

## 숨기기

상태 표시줄을 우클릭하고 **Claude Code Chat Status**의 체크를 풉니다. 이 줄만 숨겨지고, 옆의 백엔드 점은 따로인 항목(**Claude Code**)입니다.

## 나오지 않는 곳

- **브라우저.** 브라우저에는 상태 표시줄이 없고, 채팅 화면이 이 줄의 내용을 이미 모두 보여 줍니다. 채팅 입력창에 모델, 모드, 컨텍스트 게이지가 있고, 탭 아이콘이 Claude가 일하는 동안 돌고 기다릴 때 배지가 붙습니다([066](../066-session_activity_markers/ko.md)).
- **원격 개발의 JetBrains Client.** 채팅은 호스트 쪽 IDE에 보고하므로 줄은 호스트 쪽에 있습니다.

## 동작 방식

채팅 화면은 이 내용을 이미 모두 압니다. 채팅 입력창에 컨텍스트 게이지, 모델, 모드를 그리고, 탭에 작업 중·대기 상태를 그립니다. 그중 무엇이 바뀔 때마다, 그리고 채팅을 클릭해 들어올 때마다 줄과 툴팁을 플러그인 백엔드에 보냅니다. 백엔드는 무언가 바꾸는 것만 IDE에 넘기고, IDE가 상태 표시줄에 그립니다. 저장하는 것은 없습니다. 재시작하면 채팅이 열리면서 줄이 다시 채워집니다.

## 한계

- **컨텍스트 숫자는 답이 한 번 와야 나옵니다.** 다시 연 대화는 다음 답이 올 때까지 숫자가 없습니다. 채팅 입력창의 게이지와 같습니다. Claude Code가 컨텍스트 창의 크기를 답마다 알려 주기 때문입니다.
- **비용은 보여 주지 않습니다.** CC GUI의 줄도 토큰만 보여 줍니다. 답 하나가 쓴 양은 그 답 아래 줄([091](../091-reply_duration_and_tokens/ko.md))에서, 플랜 한도는 사용량 패널에서 봅니다.
