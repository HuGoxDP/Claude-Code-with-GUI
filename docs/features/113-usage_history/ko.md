# 지난 며칠 동안 Claude를 얼마나 썼고, 비용이 얼마였는지 보기

> Language: [English](./en.md) · **한국어**

**설정 → Usage**는 지금 플랜 한도가 얼마나 남았는지를 보여 줬습니다. 그동안 실제로 얼마나 썼는지, 어느 날이 많았고 어느 프로젝트가 가장 많이 썼고 비용이 얼마였는지는 보여 주지 않았습니다. 한도 아래에 새로 생긴 **History** 섹션이 지난 7일, 30일, 90일에 대해 그것을 보여 줍니다. CC GUI 플러그인의 사용량 대시보드를 가져왔습니다. CC GUI는 대시보드를 따로 설치해 띄우는 별도 도구에서 가져오지만, 여기서는 Claude Code가 이미 컴퓨터에 남기는 대화를 바로 읽으므로 설치할 것이 없습니다.

## 기록

![7일 History 섹션: 타일 넷 — Tokens 1.9M(184 input · 132.2K cache write · 1.7M cache read), Output 16.1K(Replies: 92), Cost $1.72(As Claude Code recorded it), Sessions 22(Projects: 2). 그 아래 Oct 6부터 Oct 12까지의 막대그래프에 Oct 6, Oct 7, Oct 12 막대가 Output, Input and cache write, Cache read 세 색으로 있고, By project 표에 demo-project(1.8M 토큰, 출력 16.1K, $1.67)와 probe(49.7K, 12, $0.06).](./assets/week.png)

오른쪽 위에서 **7 days**, **30 days**, **90 days**를 고릅니다. 기간은 오늘 끝나고 자정에 시작하며, 둘 다 내 시간대 기준입니다. 그래서 "7 days"는 오늘과 그 전 엿새입니다. 옆의 화살표는 대화를 다시 읽습니다.

타일 넷이 기간을 합산합니다.

- **Tokens**: Claude가 읽고 쓴 전부입니다. 아래에 새 입력, 프롬프트 캐시에 쓴 입력, 캐시에서 다시 읽은 입력으로 나눠 보여 줍니다. 대개 캐시 읽기가 대부분입니다. Claude Code는 요청마다 지금까지의 대화를 보내고, 캐시가 그것을 싸게 만들어 주기 때문입니다.
- **Output**: Claude가 쓴 것과, 그것이 답변 몇 개였는지.
- **Cost**: 이 답변들에 든다고 Claude Code가 계산한 비용(아래 참고).
- **Sessions**: Claude가 답한 대화 수와, 그것이 몇 개 프로젝트였는지.

## 그래프

하루에 막대 하나입니다. **All tokens**는 출력, 입력과 캐시 쓰기, 캐시 읽기를 쌓아 보여 주고, **Output**은 Claude가 쓴 것만, **Cost**는 날마다 쓴 비용을 보여 줍니다. 막대에 마우스를 올리면 그날의 토큰, 출력, 비용이 나옵니다.

![같은 섹션을 30일로, Cost를 골라 본 모습: Oct 4, Oct 5, Oct 6, Oct 7, Oct 12에 초록 막대가 있고 Oct 6이 가장 높으며, 그래프 아래에 Sep 13, Sep 27, Oct 12.](./assets/month-cost.png)

## 프로젝트별, 모델별

**By project**는 프로젝트(Claude Code가 실행된 폴더, 이름으로 표시하며 마우스를 올리면 전체 경로)마다 토큰, 출력, 비용을 많은 순으로 보여 줍니다. **By model**은 답한 모델마다 토큰과 출력을 보여 줍니다. 비용 열은 없습니다. Claude Code는 비용을 모델별이 아니라 세션별로 기록하고, 이 화면은 토큰에 직접 값을 매기지 않기 때문입니다. 표마다 여섯 줄을 보여 주고, **Show all**을 누르면 나머지가 나옵니다.

## 숫자가 어디서 오는가

플러그인은 아무것도 따로 기록하지 않습니다. Claude Code는 모든 대화를 `~/.claude/projects/`(`CLAUDE_CONFIG_DIR`을 정했다면 그 폴더 아래)에 쓰고, 그 안의 답변마다 API가 돌려준 토큰 수가 들어 있습니다. 기록은 그것을 읽습니다.

- **답변은 한 번만 셉니다.** Claude Code는 답변 하나를 부분마다 한 줄씩, 같은 토큰 수를 단 여러 줄로 씁니다. [포크](../056-fork_and_rewind/ko.md)로 복사된 대화도 다시 세지 않습니다.
- **서브에이전트도 셉니다.** 서브에이전트의 답변은 대화 옆 자기 파일에 있고, 그것도 읽습니다.
- **비용은 Claude Code 자신의 수치**, 세션에서 `/cost`가 보여 주는 바로 그 값입니다. 세션의 Claude Code 프로세스가 끝날 때 Claude Code가 누적 합계를 대화에 쓰고, 세션을 이어 가면 그 합계를 이어 셉니다. 기간의 비용은 그 합계가 기간 안에 늘어난 만큼입니다.

처음에는 기간 안에 바뀐 대화를 모두 읽습니다(측정해 보니 대화 100MB에 1초 남짓). 그 뒤로는 바뀐 대화만 다시 읽습니다.

## 하지 않는 것

- **아직 열려 있는 세션의 비용은 나중에 더해집니다.** Claude Code는 세션의 프로세스가 끝날 때 비용을 기록하므로, 그때까지는 토큰만 잡히고 비용은 잡히지 않습니다. 같은 이유로 긴 세션의 비용은 그 세션이 끝난 날에 잡힙니다.
- **옛 대화에는 비용이 없을 수 있습니다.** 비용을 기록하지 않던 Claude Code 버전의 세션은 토큰만 잡히고, 기간 안에 그런 세션이 몇 개인지 섹션이 알려 줍니다.
- **청구서가 아닙니다.** Claude 구독이라면 같은 사용량을 API 가격으로 쳤을 때의 금액이고, 플랜은 이것으로 청구되지 않습니다. Claude Code가 가격을 모르는 모델을 썼다면 보이는 비용이 실제보다 적다는 안내가 나옵니다.
- **이 컴퓨터만 봅니다.** 다른 컴퓨터의 대화나 지운 대화는 들어 있지 않습니다.
- 터미널에는 세션 하나의 `/cost`가 있습니다. 여러 세션을 날짜별로 합쳐 주는 명령은 없고, 이 섹션이 같은 수치로 그 일을 합니다.
